# Binance Price Agent — Agent OS

## Overview

A read-only AI agent for Binance market data.

## Purpose

The agent provides market information such as:

* Current cryptocurrency prices
* 24-hour price changes
* 24-hour high and low
* 24-hour trading volume

## Supported Symbols

* BTCUSDT
* ETHUSDT

## Safety

This project is strictly read-only.

* Trading: disabled
* Withdrawals: disabled
* Transfers: disabled
* Account access: disabled

## Binance Integration

The project is designed to use Binance Agent OS / MCP for read-only Binance market data.

Official Binance MCP endpoint:

`https://agent.binance.com/mcp/agentic`
